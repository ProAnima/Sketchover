<h1 align="center">Sketchover</h1>

<p align="center"><b>Рисуйте поверх экрана во время созвона</b> — кисть, стрелки, блоки с Markdown, скриншоты области, лазерная указка.<br>Бесплатно, для Windows, macOS и Linux.</p>

<p align="center"><a href="README.md">English</a> · <b>Русский</b></p>

Прозрачный холст поверх любых окон. Живёт в трее и открывается одним хоткеем; зажали `Alt` — мышь работает с окнами под холстом, отпустили — снова рисуете. Продукт ProAnimaStudio, автор — Ян Панаев.

Tauri 2 (Rust) + чистый JS без сборки. Интерфейс на 11 языках, обновления через ProAnima Hub.

## Установка

Скачайте установщик для своей системы со [страницы последнего релиза](https://github.com/ProAnima/Sketchover/releases/latest).

> Первый релиз готовится. До его выхода — [сборка из исходников](#запуск-для-разработки).

| Система | Файл | Как поставить |
|---|---|---|
| Windows 10/11 | `Sketchover_X.Y.Z_x64-setup.exe` | Запустить и нажать «Установить». Права администратора не нужны. |
| macOS 11+ (Intel и Apple Silicon) | `Sketchover_X.Y.Z_universal.dmg` | Открыть и перетащить Sketchover в «Программы». |
| Linux (Ubuntu 24.04+, Debian 13+, Fedora 40+) | `Sketchover_X.Y.Z_amd64.AppImage` | Сделать исполняемым (`chmod +x`) и запустить. |
| Ubuntu, Debian, Mint | `Sketchover_X.Y.Z_amd64.deb` | Двойной клик или `sudo apt install ./Sketchover_*.deb`. |
| Fedora, openSUSE | `Sketchover-X.Y.Z-1.x86_64.rpm` | Двойной клик или `sudo dnf install ./Sketchover-*.rpm`. |

После установки Sketchover сразу открывает холст, дальше живёт в трее (на macOS — в строке меню) и запускается вместе с системой — всегда в одном хоткее от вас. Выключить автозапуск — в настройках (⚙ → «Запускать вместе с системой»). Закрытие холста только прячет его; выйти — из трея или настроек. Обновляется сам.

**Первый запуск без подписи разработчика.** Пока у установщиков нет платной подписи:
- Windows может показать «Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
- macOS может сказать, что разработчик не подтверждён → в Finder правый клик по Sketchover → «Открыть» → «Открыть». Для скриншотов macOS один раз попросит разрешение «Запись экрана».

## Запуск для разработки

Нужны Node.js и Rust.

```bash
npm install
npm start
```

`npm run build` — установщик для текущей системы (на Windows: `npm run build -- --bundles nsis`). Установщики для всех систем собирает CI — см. «Выпуск версии».

## Управление

| Действие | Как |
|---|---|
| Показать холст / рисование ⇄ сквозные клики | `` Alt+` `` (клавиша Ё) — глобально, меняется в настройках |
| Мышь — окнам под холстом, пока держишь | зажать `Alt` (macOS: `⌥`; Windows и macOS) |
| Сквозные клики вкл / выкл | двойной тап `Alt` (Windows и macOS); `Esc`, кнопка режима или глобальный хоткей |
| Спрятать в трей | ✕ на панели; показать — хоткей или клик по иконке в трее |
| Инструменты | `1` выбор, `2` кисть, `3` линия, `4` стрелка, `5` прямоугольник, `6` эллипс, `7` блок, `8` текст, `9` лазер, `0` ластик |
| Скриншот области | `S` или 📷 на панели → выделить область мышью (`Esc` — отмена) |
| Цвет / толщина | `Alt+1…8` / `Shift+1…3` или кнопки на панели |
| Отмена / повтор | `Ctrl+Z` / `Ctrl+Y` |
| Картинку в буфер (вставить в чат) | `Ctrl+Shift+C` или кнопка на панели |
| Сохранить / открыть (PNG с холстом внутри) | `Ctrl+S` / `Ctrl+O` или кнопки на панели |
| Удалить выделенное / очистить всё | `Delete` / `Shift+Delete` |
| Памятка по клавишам | `F1` или `?` на панели (по умолчанию открыта справа) |
| Настройки, обновления, о программе | ⚙ на панели |

- **Блоки**: протяни рамку или кликни, введи текст (`Enter` — готово, `Shift+Enter` — новая строка). Двойной клик по блоку или тексту любым инструментом — правка.
- **Markdown** в блоках и тексте: `#`/`##`/`###` заголовки, `-` и `1.` списки, `**жирный**`, `*курсив*`, `` `код` ``, `~~зачёркнутый~~`. Блок растёт под текст.
- **Скриншоты** появляются на месте выделенной области и сразу выделены: тащи, тяни за угол (пропорции сохраняются), вращай за круглую ручку сверху (прилипает к шагу 15°).
- **Стрелки** начинаются и заканчиваются на блоках и скриншотах и тянутся за ними.
- **Сохранение**: `Ctrl+S` сохраняет обычный PNG (открывается любым просмотрщиком) со встроенным холстом — `Ctrl+O` открывает его снова для правки; прежний холст возвращается через `Ctrl+Z`. `Ctrl+Shift+C` — картинка в буфер, сразу вставить в чат созвона.
- Клавиши — по физическим цифрам, работают на любой раскладке.
- В режиме «сквозные клики» и при зажатом `Alt` рисунок полупрозрачный, клики и прокрутка идут в окна под ним, панель остаётся кликабельной.
- Холст открывается на мониторе, где курсор. Чтобы зрители видели рисунки, делись всем экраном, а не окном.

## Выпуск версии

```bash
npm version patch
```

`npm version` (`patch`, `minor` или `major`) поднимает версию в `package.json` и `src-tauri/Cargo.toml`, коммитит и ставит тег `vX.Y.Z`. После `git push --follow-tags` GitHub Actions (`.github/workflows/release.yml`) проверяет код, собирает установщики для Windows, macOS и Linux, подписывает их для автообновления и кладёт в **черновик** релиза вместе с `latest.json`. Опубликовать черновик — вручную, после проверки; с публикацией версию видят ProAnima Hub и установленные приложения.

Секреты репозитория: `TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` — ключ подписи обновлений (публичная половина — в `src-tauri/tauri.conf.json`).

Проверки локально: `npm run check` (интерфейс), `npm test` (тесты ядра), `cargo clippy --all-targets -- -D warnings` и `cargo test` в `src-tauri/`.

## Структура

```
src/           интерфейс (ES-модули, без сборки)
  core/        состояние, фигуры, геометрия, история, Markdown, картинки — чистая логика
  tools/       инструменты с единым интерфейсом down/move/up
  ui/          холст, панель, настройки, ввод; api.js — единственный мост к Rust
  i18n/        словари 11 языков
src-tauri/     процесс ОС на Rust: окно-оверлей и сквозные клики, опрос Alt, трей, хоткей,
               настройки, снимок экрана, обновления
scripts/       проверки интерфейса (npm run check), синхронизация версии
.github/       CI и сборка установщиков по тегу
docs/ROADMAP.md  план развития
```
