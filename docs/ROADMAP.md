# Sketchover — план развития

Цель: во время созвона одним хоткеем открыть холст поверх экрана, быстро нарисовать, показать, сохранить — и вернуться к работе. Каждая фича оценивается по трём вопросам: **просто ли это пользователю, отзывчиво ли, не усложняет ли код сверх нужного.**

## Как продукт должен ощущаться

1. Приложение установлено и живёт в трее, не мешает. Один хоткей (`` Alt+` ``) — холст поверх экрана; памятка по клавишам сбоку.
2. Рисуешь сразу, без настроек: кисть, стрелки, блоки с текстом, скриншоты.
3. Зажал `Alt` — рисунок полупрозрачный, мышь работает с окнами под ним; отпустил — снова рисуешь. Тот же хоткей или `Esc` — сквозной режим без удержания.
4. Зажатое колесо — двигаешь холст, `Ctrl+колесо` — масштаб.
5. Сохранил одной кнопкой — файл открывается где угодно и при этом редактируется дальше.
6. Обновления приходят сами, через ProAnima Hub, как у остальных приложений студии.

## Ключевые решения

### Стек: переход на Tauri 2
- ProAnima Hub отдаёт обновления в формате Tauri (`latest.json` + minisign-подписи, проверка ключом, встроенным в приложение). Signal Lab подключён к хабу двумя строками конфига; в Electron это пришлось бы писать и поддерживать самим.
- Установщик ~5–10 МБ вместо ~100 МБ, меньше памяти — важно для программы, которая постоянно висит в трее.
- Переносится дёшево: весь UI (`src/renderer/` — холст, инструменты, панель) остаётся как есть, на Rust переписывается только процесс ОС (~100 строк `main.js`): окно-оверлей, трей, хоткей, IPC.
- Риски, которые проверяем первыми:
  - **Сквозные клики с кликабельной панелью.** У Tauri есть `set_ignore_cursor_events`, но нет «пересылки» движения мыши, как в Electron. Решение: в сквозном режиме Rust-сторона ~30 раз/с сверяет позицию курсора с прямоугольником панели и включает/выключает игнор. В режиме рисования опроса нет.
  - **Прозрачность:** Windows (WebView2) и macOS (`macOSPrivateApi`) — штатно; Linux — WebKitGTK, проверить на X11 и Wayland.
  - **Скриншот экрана:** Rust-крейт `xcap` (Win/macOS/Linux).
- Шаблон для обновлений, окна «О программе» и локализации — **Signal Lab** (`pas-SignalLab`): переиспользуем подход, а не изобретаем.

### Хоткеи
- Глобальный — **один**, по умолчанию **`` Alt+` ``** (две клавиши, слева сверху у Esc; на русской раскладке — Ё): холст спрятан → показать; виден → рисование ⇄ сквозные клики. Переназначается в настройках (2–3 клавиши); занятая комбинация видна сразу.
- Внутри холста — по физическим клавишам (`e.code`), на любой раскладке: `1…9, 0` — инструменты по порядку панели, `Alt+1…8` — цвет, `Shift+1…3` — толщина, `Esc` — сквозной режим, `Ctrl+Z/Y`, `Del`/`Shift+Del`, `F1` — памятка.
- **Удержание `Alt`** (macOS — `⌥`) — мышь уходит окнам под холстом, рисунок полупрозрачный; отпустил — снова рисование и фокус возвращается холсту. Работает опросом состояния клавиши (Windows — `GetAsyncKeyState`, macOS — `CGEventSourceFlagsState`), без хуков клавиатуры и особых разрешений.
  - Почему `Alt`, а не `Ctrl`: модификатор доходит до окна под холстом, а `Ctrl+колесо` в браузере — масштаб вместо прокрутки, `Shift+колесо` — прокрутка вбок. `Alt+колесо` в Chrome/Edge прокручивает как обычно.
  - Остаточные эффекты `Alt`: `Alt+клик` по ссылке в Chrome скачивает её; в Firefox `Alt+колесо` может листать историю (зависит от настроек). Если будет мешать — клавиша удержания станет настройкой.
  - Linux пока без удержания (на Wayland состояние чужих клавиш недоступно); там — переключение.
- **Двойной тап `Alt`** — сквозной режим вкл/выкл (работает и когда фокус в другом окне). Тап — Alt отпущен за ≤300 мс и без других клавиш/кнопок мыши; второй — в пределах 400 мс. Поэтому `Alt+Tab`, `Alt+Shift` и `Alt+цифра` подряд режим не переключают. Логика — чистая функция с юнит-тестами (`overlay.rs`).
- Памятка по клавишам — справа, открыта по умолчанию, сворачивается `F1`/`?`, скрыта в сквозном режиме.
- Все обращения к окну — только из главного потока; фоновый опрос лишь ставит задачи (иначе взаимная блокировка — так было в первой версии).

### Настройки и «О программе» — раскрываемая панель
- Кнопка ⚙ на панели инструментов раскрывает компактную панель под ней (не отдельное окно, не модальный диалог), повторный клик или `Esc` — свернуть.
- Содержимое, сверху вниз:
  1. **Язык** — по умолчанию язык системы.
  2. **Хоткей** — поле записи комбинации.
  3. **Запуск вместе с системой** — переключатель.
  4. **Обновления** — текущая версия, статус («актуальная» / «доступна X.Y» → «Обновить», прогресс загрузки), автопроверка при запуске.
  5. **О программе** — ProAnimaStudio · автор Ian Panaev (ru: Ян Панаев) · контакт `info@proanima.net` · лицензия.
- Настройки — JSON в каталоге данных приложения, проверяются при чтении (битый файл → значения по умолчанию).

### Локализация — 11 языков, как в Signal Lab
- ru, en, de, es, fr, pt, zh, ja, ko, ar, hi (как в Signal Lab); `ru` и `en` — эталонные, остальные проверяются на полноту ключей.
- Строки — плоские словари `ключ → текст` в `src/renderer/i18n/<lang>.js`, функция `t(key, params)`. Без библиотек.
- Подсказки на кнопках, тексты панели, сообщения об ошибках — всё через `t`. Арабский — `dir="rtl"` для панели настроек.

### Обновления через ProAnima Hub
- Плагин `tauri-plugin-updater`, эндпоинты: хаб первым, GitHub Releases запасным:
  `https://hub.proanima.net/v1/sketchover/update/{{target}}/{{arch}}/{{current_version}}`.
- Случайный `install_id` (UUID, создаётся один раз) в заголовке `X-Install-Id` — для поэтапной раскатки.
- Подпись: ключ minisign студии (публичный — в конфиге, приватный — только в CI релиза).
- Проект `sketchover` заводится в хабе: `pas-hub project add sketchover --name Sketchover --repo ProAnima/Sketchover`.
- Статистика хаба (запуски, версии) — только обезличенный id, без личных данных; включаем по решению студии.

### Камера холста (панорама и масштаб)
- Фигуры хранятся в **мировых координатах**, отображение через `view = { x, y, scale }`. Хит-тесты переводят экранные координаты в мировые.
- Зажатое колесо — панорама, `Ctrl+колесо` — масштаб к курсору, кнопка «сбросить вид».
- Делать **до** скриншотов и сохранения: потом переводить координаты дороже.

### Скриншот области
- Кнопка/клавиша в холсте → прячем оверлей → снимаем экран (`xcap`) → рамка выделения → кусок становится фигурой `image`.
- Нельзя скрывать оверлей от захвата экрана (content protection): тогда его не увидят и зрители демонстрации.
- macOS требует разрешения «Запись экрана», Wayland — через портал; отказ — понятное сообщение.
- `image`: перемещение, масштаб за угол, **поворот** за отдельную ручку (`rotation`).
- Картинки хранятся отдельно (`images: { id → данные }`), фигура ссылается по id — иначе история undo будет копировать мегабайты на каждое действие.

### Привязка стрелок
- Цепляются к любой фигуре с границами: нода, прямоугольник, эллипс, скриншот, текст; с учётом поворота.
- При наведении конца — подсветка цели; у выделенной стрелки концы перетаскиваются (перепривязка).

### Блоки с текстом и цвет
- Цвет рамки, заливки и текста меняется выделением + клик по цвету.
- Мини-панель рядом с выделенной фигурой (цвет, толщина, удалить) — меньше движений мышью.

### Сохранение
- **PNG со встроенной сценой** (JSON в чанке `tEXt`, как у Excalidraw): один файл открывается любым просмотрщиком, вставляется в чат и снова редактируется в Sketchover. Без зависимостей.
- `Ctrl+S` — сохранить (диалог и запись на стороне Rust), `Ctrl+Shift+C` — картинка в буфер обмена (для чата созвона).
- SVG — позже, если понадобится.

### Отзывчивость
- `getCoalescedEvents()` для карандаша, `getContext('2d', { desynchronized: true })`.
- Два слоя: статичные фигуры перерисовываются только при изменении; штрих, лазер, выделение — сверху.
- Картинки декодируются один раз в `ImageBitmap`.

### Установка ✅
- Windows — NSIS `.exe` в профиль пользователя (без прав администратора); macOS — один universal `.dmg` (Intel + Apple Silicon), без иконки в Dock; Linux — AppImage, `.deb`, `.rpm` с зависимостями трея и снимка экрана.
- Сборка — GitHub Actions по тегу `vX.Y.Z` (`npm version`): проверки → черновик релиза → установщики трёх систем, подписанные для автообновления, + `latest.json`. Публикация черновика — вручную.
- Запуск вручную сразу открывает холст (иначе после установки кажется, что ничего не произошло); автозапуск с системой (`--hidden`) — тихо в трее.
- Автозапуск включается сам при первом запуске установленной программы (не в отладочной сборке) — программа нужна на созвоне и должна уже ждать в трее. Выключил в настройках — больше не включаем (`autostartDefaultApplied`). Закрытие окна (`Alt+F4`) прячет холст, а не завершает программу.
- Linux собирается на Ubuntu 24.04: снимку экрана (`xcap` → PipeWire) нужны заголовки PipeWire 1.0, в 22.04 их нет. Поэтому Linux-сборки — для Ubuntu 24.04+, Debian 13+, Fedora 40+.
- Без платной подписи: Windows SmartScreen и macOS Gatekeeper предупреждают при первом запуске (macOS — ad-hoc подпись, чтобы не было «приложение повреждено»). Следующий шаг — сертификат подписи кода для Windows и Apple Developer ID с нотаризацией: секреты подключаются в `release.yml` без изменения кода.

### Мониторы
- Сейчас — основной. Дальше: при вызове хоткеем холст открывается на мониторе с курсором.
