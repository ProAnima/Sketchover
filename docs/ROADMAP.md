# Sketchover — план развития

Цель: во время созвона одним хоткеем открыть холст поверх экрана, быстро нарисовать, показать, сохранить — и вернуться к работе. Каждая фича оценивается по трём вопросам: **просто ли это пользователю, отзывчиво ли, не усложняет ли код сверх нужного.**

## Как продукт должен ощущаться

1. Установил — программа стартует с системой и ждёт в трее. Один хоткей (`` Alt+` ``) — холст поверх экрана; памятка по клавишам сбоку. ✅
2. Рисуешь сразу, без настроек: кисть, стрелки, блоки с текстом, скриншоты. ✅
3. Зажал `Alt` — рисунок полупрозрачный, мышь работает с окнами под ним; отпустил — снова рисуешь. ✅ (Windows, macOS)
4. Зажатое колесо — двигаешь холст, `Ctrl+колесо` — масштаб. — впереди
5. Сохранил одной кнопкой — файл открывается где угодно и при этом редактируется дальше. ✅
6. Обновления приходят сами, через ProAnima Hub, как у остальных приложений студии. ◐ (в приложении готово, нужен первый релиз)

## Сделано и как устроено

### Стек: Tauri 2
- Процесс ОС — Rust (`src-tauri/`), интерфейс — ES-модули без сборки (`src/`). Перешли с Electron ради обновлений через ProAnima Hub: хаб отдаёт формат Tauri (`latest.json` + minisign), как у Signal Lab.
- Установщик Windows — 2,4 МБ (у Electron было бы ~100 МБ); меньше памяти — программа постоянно висит в трее.
- Rust-модули: `overlay` (окно, сквозные клики, фокус), `keys` (опрос Alt), `hotkey`, `tray`, `settings`, `capture` (снимок экрана), `updates`; команды — тонкие обёртки в `lib.rs`.

### Окно-оверлей и сквозные клики
- Прозрачное окно поверх всех, без рамки и панели задач, открывается на мониторе с курсором; на macOS — без иконки в Dock (приложение строки меню).
- У Tauri нет «пересылки» движения мыши окну, игнорирующему клики (как в Electron). Поэтому, пока холст виден, фоновый поток ~30 раз/с просит главный поток проверить `Alt` и курсор: над панелью клики ловит холст, вне её — окна под ним. Холст спрятан — поток спит.
- Все обращения к окну — только из главного потока; фоновый поток ничего не ждёт и замков не держит (в первой версии было взаимное блокирование и «замерзание»).
- Фокус: окну и сразу WebView, но только если окно ещё не в фокусе — иначе сбрасывался бы фокус открытого поля ввода.
- `Alt+F4` / `Cmd+W` прячут холст, а не завершают программу; выход — из трея или настроек.

### Хоткеи
- Глобальный — **один**, по умолчанию **`` Alt+` ``** (клавиша слева от `1`; на русской раскладке — Ё): холст спрятан → показать; виден → рисование ⇄ сквозные клики. Переназначается в настройках (до 3 клавиш, нужен модификатор); если комбинацию держит другая программа — остаётся прежняя, и это видно в настройках.
- Внутри холста — по физическим клавишам (`e.code`), на любой раскладке: `1…9, 0` — инструменты по порядку панели, `Alt+1…8` — цвет, `Shift+1…3` — толщина, `S` — скриншот, `Esc` — сквозной режим, `Ctrl+Z/Y`, `Del`/`Shift+Del`, `F1` — памятка.
- **Удержание `Alt`** (macOS — `⌥`) — мышь окнам под холстом, рисунок полупрозрачный; отпустил — снова рисование, фокус возвращается холсту. Опрос состояния клавиш (Windows — `GetAsyncKeyState`, macOS — `CGEventSource*`), без хуков и особых разрешений.
  - Почему `Alt`, а не `Ctrl`: модификатор доходит до окна под холстом, а `Ctrl+колесо` в браузере — масштаб вместо прокрутки. `Alt+колесо` в Chrome/Edge прокручивает как обычно.
  - Остаточные эффекты: `Alt+клик` по ссылке в Chrome скачивает её; в Firefox `Alt+колесо` может листать историю. Если будет мешать — клавиша удержания станет настройкой.
- **Двойной тап `Alt`** — сквозной режим вкл/выкл, и когда фокус в другом окне. Тап — `Alt` отпущен за ≤300 мс без других клавиш и кнопок мыши; второй — в пределах 400 мс. Поэтому `Alt+Tab`, `Alt+Shift`, `Alt+цифра` режим не переключают. Чистая функция с юнит-тестами (`overlay.rs`).
- Одиночный `Alt` гасится в окне холста: иначе Windows уводит окно в «режим меню» и теряет следующую клавишу.
- **Linux:** удержания и двойного тапа нет (на Wayland состояние чужих клавиш недоступно) — переключение `Esc`, кнопкой или хоткеем.
- Памятка — справа, открыта по умолчанию, сворачивается `F1`/`?`, скрыта в сквозном режиме.

### Рисование
- Инструменты с единым интерфейсом `down/move/up` (`src/tools/`): выбор, кисть, линия, стрелка, прямоугольник, эллипс, блок, текст, лазер, ластик. Иконка выбора — курсор мыши (символ ↖ путали со стрелкой).
- **Блоки и текст с Markdown**: `#`–`###`, списки `-` и `1.` (продолжаются по `Enter`, пустой пункт заканчивает список), `**жирный**`, `*курсив*`, `` `код` ``, `~~зачёркнутый~~`. Блок растёт под текст. Правка — двойным кликом любым инструментом (двойной клик считаем сами: у `pointerdown` счётчик кликов всегда 0); точка, поставленная первым кликом, откатывается.
- **Стрелки и линии** цепляются к блокам и скриншотам (с учётом поворота) и тянутся за ними.
- **Скриншот области** (`S` или 📷): холст прячется → `xcap` снимает монитор → выделение мышью на замороженном кадре → кусок становится фигурой `image` на том же месте, сразу выделен: перемещение, масштаб за угол с сохранением пропорций, поворот за ручку (прилипание к 15°).
  - Картинки хранятся отдельно от фигур (`core/images.js`), фигура ссылается по id — история отмены не копирует мегабайты.
  - Оверлей нельзя скрывать от захвата экрана (content protection) — его перестанут видеть зрители демонстрации.
- Перерисовка склеивается в один кадр (`requestAnimationFrame`); в простое кадры не рисуются. Фигуры рисует `ui/shapes-draw.js` в любой контекст — на экран и в картинку для экспорта.
- История отмены — до 200 шагов и до ~50 млн символов JSON (длинные штрихи кистью); картинки, на которые не ссылаются ни холст, ни история, освобождаются перед новым скриншотом.

### Сохранение и буфер обмена
- **`Ctrl+Shift+C`** — рисунок картинкой в буфер (прозрачный фон, по границам рисунка, в разрешении экрана) — вставить в чат созвона. Через `tauri-plugin-clipboard-manager` в Rust: Web Clipboard API зависит от фокуса и «жеста пользователя» и по-разному работает в WebView разных систем.
- **`Ctrl+S`** — PNG со встроенной сценой: чанк `iTXt` (UTF-8; `tEXt` — только Latin-1), как у Excalidraw. Файл открывается любым просмотрщиком, а **`Ctrl+O`** открывает его в Sketchover для правки (прежний холст — через `Ctrl+Z`). Картинки скриншотов — внутри сцены в base64.
- Диалоги — `tauri-plugin-dialog` в Rust, с окном холста как владельцем (иначе диалог открылся бы под полноэкранным окном поверх всех). Путь выбирает человек; интерфейс передаёт только байты и подсказку имени.
- Открываемый файл недоверенный: `core/scene.js` оставляет только известные фигуры с корректными полями, ссылки стрелок — только на оставшиеся фигуры; размер файла — до 256 МБ.

### Настройки и «О программе» — раскрываемая панель
- ⚙ на панели раскрывает компактную панель под ней; повторный клик или `Esc` — свернуть.
- Язык (по умолчанию — системы), хоткей (запись комбинации), запуск с системой, обновления (версия, статус, «Обновить», прогресс, проверка при запуске), о программе (ProAnimaStudio, автор Ян Панаев / Ian Panaev, `info@proanima.net`), выход.
- Настройки — JSON в каталоге конфигурации приложения, проверяются при чтении (битый файл → значения по умолчанию).

### Локализация
- 11 языков, как в Signal Lab: ru, en, de, es, fr, pt, zh, ja, ko, ar, hi. Плоские словари `src/i18n/<lang>.js`, функция `t(key, params)`, без библиотек; арабский — `dir="rtl"` для панели настроек. `npm run check` проверяет, что у всех словарей одинаковые ключи.
- Переводы, кроме ru и en, сделаны без носителей — перед широким релизом стоит показать им.

### Установка и запуск
- Windows — NSIS `.exe` в профиль пользователя (без прав администратора); macOS — один universal `.dmg` (Intel + Apple Silicon), ad-hoc подпись; Linux — AppImage, `.deb`, `.rpm` с зависимостями трея и снимка экрана.
- Linux собирается на Ubuntu 24.04: `xcap` тянет PipeWire, которому нужны заголовки PipeWire 1.0 (в 22.04 их нет). Linux-сборки — для Ubuntu 24.04+, Debian 13+, Fedora 40+.
- Запуск вручную сразу открывает холст (иначе после установки кажется, что ничего не произошло); автозапуск с системой (`--hidden`) — тихо в трее.
- Автозапуск включается сам при первом запуске установленной программы (не в отладочной сборке); выключил в настройках — больше не включаем (`autostartDefaultApplied`).
- Без платной подписи Windows SmartScreen и macOS Gatekeeper предупреждают при первом запуске; ad-hoc подпись на macOS убирает «приложение повреждено». Сертификат подписи для Windows и Apple Developer ID с нотаризацией подключаются секретами в `release.yml` без изменения кода.

### Сборка и релизы
- `ci.yml` — на каждый пуш и PR: `npm run check` (синтаксис модулей, импорты, словари) и `npm test` (тесты ядра); `cargo fmt --check`, `cargo clippy -D warnings`, `cargo test` — на Linux, Windows и macOS.
- `release.yml` — тег `vX.Y.Z` (`npm version patch|minor|major` + `git push --follow-tags`): проверки → черновик релиза → установщики трёх систем, подписанные для автообновления, + `latest.json`. Публикация черновика — вручную.

### Обновления через ProAnima Hub
- `tauri-plugin-updater`: хаб первым, GitHub Releases запасным — `https://hub.proanima.net/v1/sketchover/update/{{target}}/{{arch}}/{{current_version}}`.
- Случайный `install_id` (UUID) в заголовке `X-Install-Id` — для поэтапной раскатки. Больше ничего в сеть не уходит.
- Подпись: собственный ключ minisign Sketchover (не общий с Signal Lab — утечка одного не затронет другое). Публичный — в `tauri.conf.json`, приватный и пароль — только в секретах CI (`TAURI_SIGNING_PRIVATE_KEY`, `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`) и у владельца в `~/.tauri/sketchover-updater.*`.

## Открытые вопросы
- Один холст или несколько досок? Пока — один.
- Автосейв последнего холста при выходе и обновлении — склоняюсь к «да»: формат файла уже есть.
- Отзывы через хаб (форма + скриншот холста) — хаб умеет; нужно ли в Sketchover?
- Статистика использования через хаб: сейчас не отправляется; включать ли и по умолчанию ли.
- Удержание и двойной тап `Alt` на Linux X11 (на Wayland невозможно).
