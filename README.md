# Sketchover

Маленький бесплатный оверлей: рисуй поверх любых окон (в том числе во время звонка) — карандаш, линии, стрелки, прямоугольники, эллипсы, ноды с текстом, подписи и лазерная указка. Electron, без сборки.

## Запуск

```bash
npm install
npm start
```

## Управление

| Действие | Как |
|---|---|
| Рисование ⇄ сквозные клики | кнопка на панели, `Ctrl+Alt+D` (глобально) или `Esc` |
| Скрыть / показать оверлей | `Ctrl+Alt+H` (глобально) |
| Очистить всё | `Ctrl+Alt+C` (глобально) или 🗑 |
| Инструменты | `V` выбор, `P` карандаш, `L` линия, `A` стрелка, `R` прямоугольник, `O` эллипс, `N` нода, `T` текст, `K` лазер, `E` ластик |
| Цвет | `1`–`8` или кружки на панели |
| Отмена / повтор | `Ctrl+Z` / `Ctrl+Y` |

- **Ноды**: протяни рамку или кликни, введи текст (`Enter` — готово, `Shift+Enter` — новая строка). Двойной клик в режиме выбора правит текст.
- **Стрелки** начинаются/заканчиваются на нодах и тянутся за ними при перемещении.
- В режиме «сквозные клики» рисунок остаётся на экране, а клики идут в окна под ним; панель остаётся кликабельной.
- Оверлей покрывает основной монитор. Чтобы зрители видели рисунки, делись всем экраном, а не отдельным окном.
